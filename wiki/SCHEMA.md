# Wiki Schema

## Domain
Personal knowledge base for Naz (HERO e-waste pickup driver).

## Page Types
- entity: People, organizations, products
- concept: Ideas, methods, topics, processes
- source: Document summaries
- synthesis: Cross-source analysis
- comparison: Side-by-side comparisons

## Tag Taxonomy
- **People:** person, family, friend, colleague, contact
- **Health:** health, medication, condition, symptom, diet, goal, exercise
- **Work:** work, hero, pickup, logistics, client, side-hustle, income
- **Finance:** finance, bill, expense, income, budget
- **Tech:** project, app, dev, automation, tool, vps
- **Life:** life, home, vehicle, location, preference, event, hobby
- **Meta:** meta, process, convention, lesson, reference
- **Media:** show, anime, movie, book

## Conventions
- Use [[wikilinks]] for cross-references — minimum 2 outbound links per page
- Frontmatter on every page (title, created, updated, type, tags)
- Tags must come from the taxonomy above
- File names: lowercase, hyphens, no spaces
- Sources are immutable in raw/sources/
