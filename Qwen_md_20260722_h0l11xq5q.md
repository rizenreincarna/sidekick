## Summary

Redesigns RizenCC using the Neon Cockpit design language from the HERO Sidekick / VPS System Monitor UI.

This PR:

- Adds a new Cockpit home tab
- Converts the app to a 5-tab control center:
  - Cockpit
  - Voice
  - Server
  - Orders
  - Settings
- Replaces the old green glass theme with a dark neon teal/cyan theme
- Adds reusable Neon UI components:
  - NeonCard
  - NeonHeroCard
  - NeonChip
  - NeonProgress
  - NeonStatTile
  - NeonQuickAction
  - NeonTopBar
  - NeonBottomBar
  - NeonSegmentButton
- Preserves existing ViewModel, API client, voice logic, TTS, stats, and order logic
- Removes hardcoded stats-history credentials and uses the authenticated Retrofit client instead

## UI Changes

- New top telemetry bar with sync pulse and refresh action
- New Cockpit screen with:
  - hero status panel
  - quick actions
  - CPU/memory/disk/network summary
  - API balances
  - delivery snapshot
- Voice tab redesigned with neon chips and neon mic state
- Server tab redesigned with neon telemetry cards and sparklines
- Orders tab redesigned with neon stat tiles and day cards
- Settings tab redesigned with neon voice engine controls

## Security

- No secrets are included in this PR
- Existing `Constants.kt` should be moved to secure config / BuildConfig before release
- Rotate any previously exposed Basic Auth or signing secrets
